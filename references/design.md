# 视觉设计规范

目标：克制、统一、有呼吸感。同一时刻只有一个视觉焦点。

## 配色（选一套，全片不换）

每套 = 底色 + 主文字 + 一个主强调色 + 2~3 个语义色。

| 名称 | 底 | 文字 | 主强调 | 语义色 | 适合 |
|---|---|---|---|---|---|
| 暖夜（默认） | `#0c0b0a`→`#1e1b18` 径向 | `#f1ebdf` | 陶土 `#d97757` | 琥珀 `#f2b36b`、鼠尾草 `#93c4a2`、天蓝 `#88b3e2`、玫瑰 `#ec7f76` | 科普、AI、叙事 |
| 纸本 | `#f2ead9` | 墨 `#2b2622` | 朱 `#c4553a` | 青 `#5b8a8a`、黛 `#4a5568` | 人文、历史、手绘 |
| 深海科技 | `#05070d`→`#0b1220` | `#e6edf7` | 青 `#4fd1c5` | 紫 `#9f7aea`、蓝 `#63b3ed`、橙 `#f6ad55` | 科技、数据、产品 |
| 白昼极简 | `#fafaf7` | `#111111` | 电光蓝 `#2563eb` | 灰阶 + 绿 `#16a34a`/红 `#dc2626` | 商务、教程、发布会 |
| 霓虹 | `#0a0612` | `#f5f3ff` | 品红 `#ff3d81` | 青 `#00e5ff`、黄 `#ffd60a` | 游戏、潮流、MV |

规则：
- 语义色固定含义（绿=成功、红=失败、蓝=工具/系统……），全片一致。
- 浅色背景上字幕/标题用深色（`KIT.drawCaptions(..., { color: '#2b2622', shadow: false, band: false })`）。
- 发光只用在主强调色上；`globalCompositeOperation='lighter'` 叠加光晕。

## 字体与字号（1080p 基准，其他画幅按 `U = min(W,H)/1080` 缩放）

| 用途 | 字体 | 字重 | 字号 |
|---|---|---|---|
| 片名 | Noto Serif SC（衬线） | 600 | 90~120，字距 0.1em |
| 章节标题 | Noto Serif SC | 600 | 80~96 |
| 正文/说明 | Noto Sans SC | 400~500 | 28~40 |
| 字幕 | Noto Sans SC | 400，强调 600 | 横屏 36；竖屏 W/22（约 49） |
| 标签/角标 | Noto Sans SC | 500，字距 2~6px | 16~22 |
| 代码/数字 | Cascadia Code / Consolas | 400~600 | 20~56 |
| 手写感 | 华文行楷 / 楷体 | 400 | 80~120 |

macOS 回退：PingFang SC / Songti SC（canvas-kit 已内置回退链）。

## 构图与安全区

- 横屏：内容在左右各 80px、上下各 60px 以内；字幕基线 y = H − 50。
- 竖屏（9:16）：上 12% 和下 18% 是平台 UI 区，重要内容放在 15%~78%；字幕放 80% 高度。
- 三分法：主体放在三分线交点；标题居中时下方留出 1/3 空白。
- 留白比填满更高级：每个画面最多 3 组信息块。
- 层次：背景（暗、慢）→ 中景主体（亮、动）→ 前景文字（最清楚）。

## 动效参数

| 动作 | 时长 | 缓动 |
|---|---|---|
| 元素进场 | 0.5~0.9 秒 | `E.out3` / `expo.out`（快出慢停） |
| 元素出场 | 0.3~0.5 秒 | `E.in2` / `power2.in`（比进场快） |
| 逐字/逐个错开 | 0.06~0.1 秒/个 | — |
| 位置移动 | 0.8~1.5 秒 | `E.inOut3` |
| 弹性强调 | 0.6 秒 | `E.outBack` / `spring` |
| 镜头呼吸 | 周期 20~30 秒，幅度 1% | 正弦 |
| 关键时刻推镜 | 0.2 秒脉冲，1.5~2% | `pulse()` |

原则：
- 同一类元素用同一套参数（一致性比花样重要）。
- 动作要有因果：A 发出 → 飞向 B → B 产生反应（闪光/涟漪/音效）。
- 不用线性运动（除了进度条/时钟）；不同时动超过 3 组元素。

## 转场目录

| 转场 | 实现 | 适合 |
|---|---|---|
| 交叉淡化 | 两层 alpha | 默认、平静 |
| 黑场过渡 | 0.5 秒压黑再亮 | 章节切换 |
| 章节卡 | 暗场 + 编号 + 标题逐字 | 大段落 |
| 推拉缩放 | 旧画面放大淡出、新画面从 0.94 放大到 1 | 进入细节 |
| 光点牵引 | 一个光点从旧场景飞到新场景位置 | 有母题时最佳 |
| 擦除 | 着色器或矩形遮罩扫过 | 科技感 |
| 冻结 | worldT 停住 + 去饱和 + 故障切片 | 暂停/打断 |

## 质感层（最后叠加）

`KIT.drawGrainVignette(ctx, t)`：颗粒 0.06~0.09 + 暗角 0.5~0.65。背景再加缓慢漂移的大光斑（alpha 0.04~0.08）和浮尘。纸本风用纸纹（低频噪声）代替颗粒。

## 画幅

- `film new --size 9:16` 后模板已按比例布局；自己写的坐标一律用 `W*比例`、`H*比例`、字号乘 `U`。
- 竖屏信息纵向排列（上标题、中主体、下字幕），横屏信息横向排列。
- 同一内容出横竖两版：建两个项目共享 `src/scene.js` 逻辑，或在代码里按 `H > W` 分支布局。
