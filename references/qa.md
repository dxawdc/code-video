# 审片与交付清单

审片 = 真正打开 `film stills` / `film sheet` 生成的 sheet 图片逐张看。每张图对照下面的清单写下问题，再改代码。

## 画面（每张 sheet 都过一遍）

- [ ] **文字**：没有重叠、没有越出画面或被裁切、没有缺字方块（□）、没有被前景遮住的关键字
- [ ] **对比度**：浅底深字、深底浅字；字幕在任何背景上都清楚（必要时加阴影/底带）
- [ ] **焦点**：每张图一眼能看出主体；同时出现的信息块 ≤ 3 组
- [ ] **对齐**：移动的元素落点和目标对齐（卡片文字与终端标题、光点与节点）；列表/卡片左右对齐
- [ ] **安全区**：重要内容不贴边；竖屏避开上 12%、下 18%
- [ ] **一致性**：同类元素颜色、字号、圆角、动效参数一致；语义色没用乱
- [ ] **空洞/拥挤**：没有大面积无意义空白；没有塞满的画面
- [ ] **首尾**：开头淡入、结尾淡出到黑；第 0 帧全黑是正常的
- [ ] **3D/着色器**：没有过曝成纯白、没有法线噪点/奇点黑洞、辉光没糊住文字
- [ ] **手绘**：线条抖动自然（一拍三），没有每帧都完全不同导致闪烁

## 时间

- [ ] `film lint` 无 ✗；! 提醒逐条处理或确认
- [ ] 字幕与对应画面同时出现（抽字幕出现时刻的帧看）
- [ ] 每幕时长与分镜一致；没有拖沓的空镜（> 3 秒无变化）
- [ ] 旁白与画面信息对得上；旁白之间留了气口

## 声音

- [ ] `out/soundtrack.wav` 比时间表新（lint 会提醒）
- [ ] 关键动作都有音效；音效时刻与画面动作同帧
- [ ] 说话时配乐被压低
- [ ] verify 响度 −16~−14 LUFS，真峰值 ≤ −1 dBTP
- [ ] **说明未经人耳试听**

## 技术（film verify 自动检查）

- [ ] H.264 yuv420p、帧数与时长一致、AAC 48k 立体声
- [ ] 中段无 >1 秒全黑
- [ ] 浏览器类：`out/render-log.json` 的 `browserErrors` 为空

## 交付物

- [ ] 母版 `_1080p30.mp4`（或 `_宽x高p30`）
- [ ] 分享版 `_分享版.mp4`（发给用户）
- [ ] 封面三种比例
- [ ] README：讲了什么、文件表、如何修改、复现命令
- [ ] 可选：SRT / 软字幕版 / GIF

## 常见问题 → 修法

| 现象 | 修法 |
|---|---|
| 字幕看不清 | 浅底改深色字；或 `band: true` 加底部渐变带；或加 `shadow` |
| 标题被 3D 物体挡住 | 文字层放在 3D 合成之后画；或调镜头；或给文字加暗色光晕 |
| 卡片“飞到”的位置和目标差一点 | 用目标元素的实际坐标计算落点（宽度先 measure） |
| 画面很空 | 加背景光斑/浮尘层；或把主体放大到占画面 40~60% |
| 节奏拖 | 缩短静止段；每 3~6 秒给一个变化 |
| 水彩每帧闪烁 | 用一拍三（`HOLD_FPS = 10`）+ `randomSeed(帧号)` |
| 发光物体过曝成白块 | 发光强度降到 2~3；降低辉光强度/提高阈值 |
