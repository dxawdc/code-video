# 叙事、分镜与文案

## 先回答三个问题

1. **一句话主旨**：外行听一遍能复述。例：“按下回车后，我其实是在一遍遍重读整页对话。”
2. **观众是谁**：决定术语密度和节奏。
3. **看完记住什么**：最多 3 件，结尾回顾就回顾这 3 件。

## 结构模板（按类型选）

### 科普讲解（60~150 秒）
| 段 | 占比 | 作用 |
|---|---|---|
| 冷开场 | 5~10% | 一个具体动作/问题抓人（“某天你敲下一句话”），不先讲定义 |
| 片名 | 3~5% | 片名 + 副标题 |
| 第 1~3 章 | 各 20~25% | 每章一个概念：现象 → 机制 → 一个反直觉的点；章节卡分隔 |
| 回顾 | 10% | 三联卡片/三句话，对应“记住的 3 件事” |
| 结语 + 片尾 | 5~8% | 一句有温度的话 + 片名 |

### 产品/功能宣传（20~60 秒）
钩子（痛点画面 3 秒）→ 产品出现 → 3 个卖点（每个 5~8 秒，一个画面一个卖点）→ 证据（数字/用户语录）→ 行动号召 + Logo。

### 数据故事（30~90 秒）
一个惊人数字 → 拆解它的来源（图表生长）→ 对比/趋势 → 结论 → 数据来源注明。数字用滚动计数，图表逐段生长，关键值高亮。

### MV / 诗意短片（按音乐长度）
按段落（主歌/副歌）分镜，副歌画面最饱满；歌词逐句出现，与节拍对齐（`bpm` 写进时间表，用 `60/bpm` 网格排动作）。

### 教程 / 演示（60~180 秒）
目标结果先放 3 秒 → 步骤 1..N（每步：要做什么 + 画面演示 + 结果）→ 常见错误 → 回放结果。

### 竖屏短视频（15~60 秒）
**前 2 秒决定留存**：开门见山给结论或冲突；每 3~5 秒一个画面变化；字幕大、居中偏下（80% 高度）；结尾留 1 秒“记忆点”画面。

## 视觉母题

选 1~3 个贯穿全片的符号，让它们**随剧情改变状态**，而不是每幕换新图形：

| 主题 | 母题示例 | 状态变化 |
|---|---|---|
| AI 如何工作 | 代表“我”的火花、上下文纸带、浮尘=世界时间 | 思考时变亮、暂停时冻结、重读时被扫描 |
| 复利 | 一颗种子 | 发芽 → 枝叶 → 一棵树（不同年份） |
| 数据增长 | 一条线 | 从平到陡，最后冲出画面 |

## 分镜表写法

```
| 时间 | 场景 | 画面 | 字幕/旁白 | 声音 |
|---|---|---|---|---|
| 0–8 | 冷开场 | 光标闪烁、打字、按回车，消息化作光点点燃火花 | 某天，你敲下一句话 | 键盘声、回车重击、绽放 |
```

每行都写“画面在做什么动作”，不写“展示 XX”这种空话。

## 字幕写作

- 一条字幕一个意思；横屏 ≤ 28 字，竖屏 ≤ 16 字；超了拆成两条。
- 阅读速度：每秒 4~6 个汉字；停留 ≥ 1.2 秒。`film lint` 会检查。
- 关键词用 `**强调**` 上色，每条最多 1~2 处。
- 口语化、短句、主动语态；少用“我们可以看到”“接下来”。
- 无旁白时字幕要能独立讲清楚；有旁白时字幕 = 旁白分句（`film tts` 自动生成）。
- 数字写阿拉伯数字，单位紧跟（“12 项测试”“3 秒”）。

## 旁白写作

- 每句 8~25 字，一句一个信息；句末留 0.3~0.6 秒气口（下一句 `t` 往后放）。
- 语速：中文自然语速约 4~5 字/秒；edge-tts 默认语速偏快可用 `rate: '-8%'`。
- 先写旁白、`film tts` 拿真实时长，再按旁白排画面（旁白驱动）。
- 旁白和画面信息互补：旁白讲“为什么”，画面演“是什么”。

## 节奏

- 镜头/画面状态每 3~6 秒变化一次（竖屏 2~4 秒）。
- 信息密度高的段落后接一个“呼吸”画面（1~2 秒无新信息）。
- 情绪曲线：开场中 → 第一章升 → 中段一个高潮或反转 → 回落 → 结尾温暖收束。配乐强度跟着这条曲线走。

## 片名与章节卡

- 片名 2~8 字，衬线体大字逐字浮现；副标题小字、加字距。
- 章节卡：编号（CHAPTER 02）+ 标题 + 一句副标题，3~4 秒，暗场。
- 结尾三句结语格式整齐（“我的……，是……。”），每句一个强调词。
