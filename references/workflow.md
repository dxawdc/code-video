# 完整工作流

每一步都有**产出物**和**验收标准**。没过验收不进下一步。

## 第 1 步：需求与约束

| 项 | 默认值 | 何时必须问 |
|---|---|---|
| 画幅 | 16:9（1920×1080） | 用户提到抖音/小红书/视频号/Reels/Shorts → 默认 9:16，不用问 |
| 时长 | 科普 60~120 秒；宣传片 30~60 秒；样片 8~15 秒 | 用户给了平台限制或“越短越好” |
| 旁白 | 无，靠字幕讲清楚 | 用户说“配音/解说/讲解”或内容很长（>2 分钟） |
| 风格 | 深色暖调、衬线标题、克制动效 | 用户给了品牌色/参考片 |
| 语言 | 中文 | — |

**产出**：在 STORYBOARD.md 顶部写下：一句话主旨、观众、记住的 1~3 件事、画幅、时长、是否旁白、技术栈。
**验收**：一句话主旨能让外行听懂；技术栈在 `film doctor` 里是 ✓。

## 第 2 步：选技术栈并新建

```bash
film doctor
film new <目录> --type <类型> --title "片名" [--size 9:16]
```

**验收**：`film preview <目录>`（浏览器类）或 `film video <目录>`（外部渲染器类）能跑出模板示例。

## 第 3 步：分镜

按 `story.md` 选结构，写分镜表（时间 | 场景 | 画面 | 字幕/旁白 | 声音）。

- 每个场景写清“这一幕让观众明白什么”。
- 定视觉母题，并写出母题在每幕的状态变化。
- 时长按节奏比例分配（开场 ≤10%，结尾回顾 10~15%）。

**验收**：只读字幕列就能看懂全片；没有一幕是“为了好看而好看”。

## 第 4 步：时间表

把分镜翻译成 `src/timeline.js`：

```js
const TL = { FPS: 30, DURATION: 96, W: 1920, H: 1080 };
TL.CAPS = [[1.4, 4.6, '某天，你敲下一句话'], ...];        // 字幕
TL.VO = [{ id: 'v1', t: 1.2, text: '……' }, ...];          // 旁白（可选）
TL.SFX = [{ t: 5.6, type: 'enter' }, ...];                // 音效
TL.SCENES = { open: [0, 11], loop: [32, 57], ... };       // 自定义：各幕起止
```

- 有旁白：先写 VO → `film tts` 拿到真实时长 → 再按旁白排画面（旁白驱动）。
- 无旁白：按字幕阅读速度（每秒 4~6 字）排时长。
- 同步更新 `film.json` 的 `duration`（Manim/Blender/校验用它）。

**验收**：`film lint <目录>` 没有 ✗；! 提醒逐条处理或确认可接受。

## 第 5 步：画面

先搭骨架（每幕的大块元素和时间），再逐幕精修。每完成一幕就抽帧看一次，不要写完全片才看。

- 读 `design.md` 定配色/字体/动效参数。
- 读 `stacks/<类型>.md` 用对 API。
- 复杂片子拆文件：`src/scenes/*.js`、`src/draw.js`（公共图元）。

**验收**：`film stills <目录> auto:12` 的每张图都通过 `qa.md` 的画面清单。

## 第 6 步：声音

```bash
film tts <目录>      # 有旁白时
node audio.js        # 或在 film all 里自动执行
```

按 `audio.md` 设计配乐强度曲线和音效。关键动作（出现、点击、转场、成功/失败、高潮）都配音效，但同一时刻只突出一个。

**验收**：`film lint` 不再提示“配乐过期”；`film verify` 响度在 −16~−14 LUFS 附近。

## 第 7 步：审片循环

```
lint → preview（看动势）→ stills auto:12（看构图）→ 改 → stills 指定时刻 → ……
```

- 每轮都要真正**打开图片看**，逐张写下问题再改。
- 至少两轮；最后一轮对成片抽帧（`film sheet <mp4> auto:9 --cols 3`）。

## 第 8 步：出片与交付

```bash
film all <目录>
film srt <目录> --embed <目录>     # 可选：软字幕
film gif <目录> --from 0 --to 5    # 可选：预览动图
```

产出：
- `<片名>_1080p30.mp4`（母版，竖屏为 `_1080x1920p30`）
- `<片名>_分享版.mp4`（发给用户这个）
- `<片名>_封面.jpg / _封面_3x4.jpg / _封面_1x1.jpg`
- `out/*.verification.json`
- `README.md`（讲了什么、文件表、复现命令）

**验收**：verify 全部 ✓；成片抽帧无问题。

## 第 9 步：汇报

模板：

> 做好了《片名》，时长 X 秒，1920×1080。分享版 X MB（已发送），母版在 …。
> 画面：……（一两句亮点）。已逐段抽帧检查；声音只测了响度（−15 LUFS），我听不到声音，建议你先听一遍。
> 想改：字幕/节奏改 `src/timeline.js`，画面改 `src/scene.js`，配乐改 `audio.js`，然后 `film all <目录>`。

## 时间预算参考（1080p30）

| 类型 | 渲染速度 |
|---|---|
| canvas / shader / dom / three | 0.1~0.2 秒/帧（2 分钟片约 6~12 分钟） |
| p5brush | 一拍三时约 0.15 秒/帧 |
| hyperframes | 240 帧约 20 秒（多进程） |
| remotion | 240 帧约 40 秒 |
| manim | 8 秒约 30 秒 |
| blender（EEVEE 16 采样） | 240 帧约 100 秒；草稿用 `--samples 8` |

长片渲染放后台，完成后再继续；不要反复轮询。
